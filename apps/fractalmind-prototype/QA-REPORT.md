# 原型 14 测试与修复记录

日期：2026-09-29。范围：单 HTML 产品原型，不含真实 Sui、原生 App 或真实 Host。

## 已修复

| 问题 | 修复 |
| --- | --- |
| 创建身份可跳过运行费准备 | 自付先保存临时备份，再检查余额；支持已有赞助方。到账后须明确提交 |
| 交易尚未确认即可修改创建资料/支付来源 | 待确认交易固定资料，刷新查询同一交易；失败后重试生成新交易 |
| 缺少失败费用和支付记录 | 显示示例估算、Gas 预算、失败扣费、余额或代付额度；费用入口可查看记录 |
| 空组织无法建立首个连接入口 | 增加 Coordinator 地址绑定、待确认与确认状态，然后接邀请码接入 |
| 无运行实例仍显示 Agent 就绪 | 按部署、暂停、可达性和授权显示状态 |
| 没有匹配运行环境也承诺 OKR 自主推进 | 创建/激活时检查工作区、责任 Agent、主机与授权；允许保存候选 |
| 无源主机时无法做首次分配 | 首次分配允许选择有效目标；已失联源主机仍要求核对结果 |
| 设备锁定/未同步数据仍可进入部分内容入口 | 组织设置和组织内容统一检查数据访问；执行和主机日志也检查授权 |
| 导出包含其他组织或多余档案字段 | 完整导出仅包含当前组织；记忆导出只含当前组织记忆 |
| 不合法的记忆编辑提前修改原记录 | 先验证再写入，空白编辑不改变旧内容 |
| 表单缺少业务校验 | 补齐 OKR、边界、Coordinator URL、身份草稿校验及选择值恢复 |
| 模拟离线后恢复操作被权限检查挡住 | 重连独立检查设备授权，不要求当前已在线 |
| 多个窗口互相覆盖同一档案 | 旧窗口停计时器和写入，持续提示刷新；提示不被普通 toast 清除 |
| 异步回调可污染切换后的档案 | heartbeat、任务完成、邀请码确认关联原状态上下文 |
| 新身份档案难以找回或被重置覆盖 | 独立活动档案与已保存档案列表；新身份重置切换到独立样例 |
| 手机缺少 Agents、记忆、审批等入口 | 新增「全部功能」，首次使用优先展示当前步骤，补齐新增中英文 |

## 本轮浏览器实测

使用内置浏览器，`review=qa` 与 `review=onboarding` 隔离档案；未修改原有 Human 的组织/OKR/Host 内容。

- 桌面逐页检查工作台、OKR、主机、Agents、记忆、审批、组织、开放网络、设置、身份；检查主要内容横向溢出。
- 自付新身份：零余额拦截 → 临时备份 → 0.005 不足额 → 刷新保留 → 0.030 模拟到账 → 明确提交 → 执行失败扣 0.0006 → 重试确认；创建空组织并提示恢复包。
- 代付新身份：无赞助方、离线、额度不足、Sui 不可用均拦截；恢复后确认创建，保留支付记录；返回资料时保留 Android/本地密码选择。
- 待确认交易刷新仍显示同一创建资料和支付来源；不能退回修改已提交资料。
- 新组织从零绑定 Coordinator → 创建一次性邀请 → 新 Host 使用 → 首次在线及默认执行实例。
- 新 Host 的首个 OKR：选择未部署 Designer 时拒绝执行，切换已部署 Builder 后成功启动，并显示正确主机。
- 工作台注入偏航 → 请求新方案 → 执行暂停 → 用户采纳 → 路线 B 继续；费用、权限及成功标准保持原约定。
- 锁定身份后组织设置内容受保护；模拟解锁恢复。
- 主机 status 可读；Shell 操作先显示目标/参数确认，再产生模拟回执。
- 模拟设备离线 → 重连成功；跨窗口修改触发旧窗口刷新提示，旧窗口不覆盖新值。
- 空白记忆编辑被拒绝；搜索仍能找到原记忆。
- 新建第二个身份后，能切回第一个 QA Human，原组织和已接入 Host 仍在。
- 手机预览检查 Agent 列表、完整功能菜单、首次费用准备、费用页与主机控制台；检查中英文和浅/深主题。

## 实现边界

- 所有余额、费用、链上确认、Host 连接和 Agent 回复均为本地演示。没有真实转账、命令执行或密钥生成。
- 费用估算和扣费只接入首次身份/组织创建；Host、Agent、OKR 后续操作尚未组成完整运行费用账本。
- 浏览器缓存模拟链上权威状态；未验证真实合约安全、链上 Gas、真实设备密码学、网络重连或原生五平台兼容性。
- 手机检查使用浏览器的 390px 容器预览，未声称通过 iOS/Android 真机测试。系统主题监听保留；本轮实测显式浅色/深色。
- 既有内容和命令输出保留原语言；不承诺用户输入被翻译。领域回归无 DOM，不能证明所有 UI 组合都已覆盖。
- 本轮两个主要浏览器评审档案的错误/警告日志均为空；`git diff --check` 通过。
