# v0.2.0：已有实例的仅观察导入

基线：PRD v0.11 J11、FR-39 与 `fractalmind-app-prototype-v2`。本增量接通发现后的链上登记；完整 v0.2.0 尚未验收。

## 用户流程

1. 在安装后的 App“团队与 Agents”读取 Host 的签名扫描。只有扫描有效、原生连续性已观测的实例提供“导入为仅观察”。
2. 核对组织、Host、实例 ID、pane 和工作区／指纹，确认保留原进程和任务。tmux 不获得约束执行或 OKR 接管权限。
3. 核验当前设备的主机管理与读取权限、Host 当前成员指针和扫描，再展示付款地址、网络、余额、预计 Gas、上限及报价期限。资金不足时展示当前网络的补充资金提示。
4. 用户确认支付后，重新读取来源。原生签名返回后再次验证权限、扫描和报价，防止系统授权等待超过期限。原摘要先写技术 journal，再由已有交易管理器广播。
5. 成功后按回执的精确输出版本、`AgentImported` BCS 事件与组织实例目录核验关联。列表显示链上记录 ID 和实例 ID；登记成功不代表当前进程在线或具备消息投递能力。
6. 结果未知、刷新或重启后使用“恢复导入交易”查询原摘要。恢复前不把新选择替换进旧尝试；链上事件足以重建登记记录，不需要缓存 Host 快照或工作区。

## 权威与幂等

- 选择只在页面内存中。控制器独立调用生产 `CoordinatorReadClient.readHosts`，不能信任页面传入的 Host 状态；读取后再复核链上成员、入口版本和表 ID。
- `InstanceKey{host_address, instance_id}` 是组织目录中的精确键。同名或同 ID 的其他 Host 不合并；仅确切的动态字段不存在才能解释为未导入，RPC 失败不能解释为目录为空。
- 已登记且来源一致时返回原记录，App 不再报价或支付。冲突、撤销或需要关联新成员资格时要求单独核对；不自动重新绑定。
- 同一 PTB 中的合约权限与成员校验仍会拒绝过期／撤销。若其他授权者在最后检查之后并发完成登记，合约返回同一记录并发出 `duplicate=true` 事件。App 能重建这种没有新建对象的回执；已提交交易仍可能产生实际 Gas。
- 索引指针与共享记录须匹配组织、Host、实例、成员、运行时、工作区指纹、控制标签和撤销状态。回执同时核验事件的发送者、执行包、类型与组织，不能用其他包／组织的同名事件证明导入。
- 本地仅保存尝试 UUID、原生设备资料名、公开 Grant ID，以及原摘要／Gas 技术 journal；没有交易正文、签名、工作区、扫描或私钥。唯一业务持久关联仍在 Sui。

## 已完成验证

- [生产控制器测试记录](evidence/v020-agent-import-unit.json)：App **80/80**，包括未确认、陈旧／未知／消失／未核实扫描、工作区变化、报价后撤销、取消与旧报价、精确缺失字段、来源污染、Host 命名空间及回执重建。原生签名返回时的权限／工作区变化和取消均拒绝释放交易给广播器。
- [真实 localnet 记录](evidence/v020-agent-import-localnet.json)：**16 项检查、12 笔确认交易**。实际 tmux／内核观测经 Host 签名到生产 App，创建 `tmux-observe`、`control_confirmed=false` 登记。注入执行响应与首次查询丢失后，新控制器仅查原摘要、原交易一次广播；正常重复导入无新报价／付款。
- 同一链测试额外主动发送一次合约重复请求以验证并发回执形状；它付了实际 Gas，返回同一记录。它是合约验收夹具，不是 App 正常重复处理行为。
- [浏览器走查](evidence/v020-agent-import-browser.json)：读取真实链上登记及完整记录 ID，修复长实例 ID 溢出；中文白天和英文黑夜展示，网页签名／恢复按钮禁用。没有注入假实例。安装后对话框、IndexedDB 重启恢复及 OS 密钥库完整旅程仍未验收。

本次继承 envd 真实发现实现，不改变合约和 Go 运行时。完整链脚本仍使用生成的测试钥和 App 内存 journal；该证据不能替代安装后原生流程。

重现链上验收（已有运行中的 localnet、正确部署文件及 Go 辅助程序）：

```sh

FM_ENVD_JOIN_CLI_BIN=/tmp/fm-envd-agent-discovery-tests \
FM_ENVD_CHAIN_CONNECTION=1 FM_ENVD_AGENT_DISCOVERY=1 FM_ENVD_AGENT_IMPORT=1 \
node --import tsx scripts/host-admission-localnet.ts DEPLOYMENT.json NEW_REPORT.json
```

## 剩余目标

支持约束的适配器、安全检查点与原执行停止、重新绑定、纳入 ACTIVE OKR、明确继续，以及对话／介入和自主验证闭环仍需完成。tmux 仅观察不会自动升级成这些能力。

原生 App 的系统密钥库授权仍待用户处理；实际云 TLS Host、Windows 原生发现、五平台安装／运行及完整身份旅程保持未验收。目标范围不变。
