## 用户交互

- 团队与 Agents 的受管理实例、工作台负责实例均提供「与 Agent 沟通」。窗口固定组织、Host 和实例，不用显示名称替代身份。
- 当前适配器支持零工具状态查询与明确文件读写；通用模型问答明确显示待接入。网页只能查看公开上下文，不能签名或解密私有消息。
- 显示常驻权限版本、动作、目录、单消息工具上限、有效期、已用／预留／总额度，以及独立的单次审批账本。总额度不按日重置；每日配额属 #52。
- 管理设备可设置、调整、续期或撤销权限。每次修改单独报价、确认和原生签名，旧消息不会得到新版本的执行资格。
- 本次请求可以声明与常驻权限不同的目录、动作及额度。文件必须位于本次声明的边界内；超出常驻权限的原因逐项展示，申请的批准只绑定原消息、内容与预算，不扩大常驻权限。
- 消息保存、单次审批决定、执行能力、原 Run 准备和实际投递分别呈现。每笔上链操作独立确认费用；Run 准备完成后仍须明确发送。
- 显示原 Host 加密回应、预算结算及 Run 状态。投递回应不直接标记为执行成功；未知结果只查询原请求，重新打开不重发。排队／运行中原 Run 可请求停止，停止完成以原 Run 为准。
- 关闭、切换实例、页面隐藏或设备期限到达时释放私有正文与可操作报价。中英文、明暗主题与窄屏布局沿用 v2。

## 当前事实与恢复

`NativeDirectAgent` 使用当前设备授权、Human 代次、组织密钥版本、Host 活跃指针、受管理实例、常驻权限和工作区占用版本。签名前后、报价前后及投递前复查同一来源；durable 投递标记写入后再复查，防止等待期间权限变化。

SDK 新增精确可选权限查找、原不可变消息定位、原审批／Run 目录读取和同 Host 同工作区占用查询。只有精确动态字段缺失表示未创建；错误对象、不同类型、来源替换和传输失败不能当作空目录。

正文通过 OS 密钥库加密／解密。IndexedDB 只保存技术交易日志，localStorage 只保存公开 request ID、消息定位与已尝试投递标记；正文、目录计划、密钥及可重发命令不进入客户端持久产品状态。重开先查询保留的原请求；历史缺失不能推导为未投递。

空技术 journal 可以从 Sui 重建原消息及结果，但不能据此获得重发资格。撤销／到期权限保留历史读取和原停止入口；当前有权设备仍须通过鉴权。撤销不会删除链上历史。

## 前序失败与范围限制

R15 已终止，OS 测试凭据清理确认。原权限调整交易成功，随后 `create_message` 在模拟时因期限超出 Sui Clock 的 300000 ms 上限而拒绝，未广播正式 App 消息或投递。控制器将期限取 Sui Clock、客户端时间加 240000 ms，以及权限／设备／Host 到期时间的最小值；R16 完整通过。R15 原权限仍在链上，不把本机凭据清理称为链上撤销；没有重放原请求。

R16 的人决定由脚本显式提供；原生桥为隔离子进程，Host 密钥及技术 journal 为内存，Coordinator 为同机 loopback。后续 durable 标记复核、approve-only 设备处理及请求目录编辑由最终单元／构建证据覆盖，不伪称已在 R16 安装界面验证。
