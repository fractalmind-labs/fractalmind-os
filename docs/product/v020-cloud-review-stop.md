# v0.2.0：原云审阅停止结算与 envd 升级

基线 `06d6cf3`。复用原 Ubuntu 云 Host、Android 安装版密钥、Human、组织和 localnet，处理[前次云审阅](v020-cloud-okr-rpc.md)留下的原 RUNNING。完整云 OKR 和 v0.2.0 仍未验收。

## 产品与运行实现

- App 的“查看原审阅”增加“停止原审阅 · 查看费用”，使用当前组织操作权限和原 Run。过期审阅仍可停止；报价、签名与提交相互独立，签名前后复查权限和来源，未知回执只查询原摘要。
- 界面分别显示停止交易已确认但状态尚未同步、停止请求已上链等待 Host 回应、原审阅已取消。停止成功不会乐观显示任务结束，也不会批准约定或推进 KR。
- envd 增加 `--settle-stopped-review` 维护入口。它只加载现有 Host 密钥，不启动适配器或队列。原设备签名、载荷哈希、精确 Run／Host／受管实例、零预算、无执行合同、链上停止标记以及命令／物理审阅过期都必须通过。
- Host 通过已有 Move 结算函数发布原 Run 的加密取消回执，预算结算为零。该入口只处理无工具执行的交接观察；不能据此接管未知写入任务、延长租约或生成 Host 接受证明。它是 Host 维护操作，尚未接成运行时自动处理孤立审阅的路径。

维护入口读取 stdin 对象 `{ "execution_id": "原完整 Run ID", "command": 原签名命令 }`，上限 128 KiB；保留签名覆盖的紧凑载荷字节，不重新格式化。必须先由 App 明确提交停止。输出只包含 Run、状态、原结算摘要及错误码；若已产生摘要而回执未知，只查同一摘要／Run。
