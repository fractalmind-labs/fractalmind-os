# 新建组织：待完成的真实浏览器截图

此目录刻意没有用生成图片或静态 mock 代替实际 UI 截图。2026-11-04 的实现环境返回
`browser access host is unavailable`，没有可控制的浏览器，因此无法完成浏览器验收而不
虚构证据。

在有可用浏览器的开发环境中，运行 App 后需要分别在日间和夜间主题记录以下同屏截图，
并与 `fractalmind-app-prototype-v2/js/view-org.js` 的 `org-new` / `org-made` 对照：

1. “我的组织”页和组织菜单中的“新建组织”入口；
2. 根设备的名称、简介、重复名称提示、费用报价与签名前待确认状态；
3. 已确认后的工作台和“组织已建好”提示；
4. 非根设备的“只有主设备能新建组织”说明及可用主设备列表。

预期差异仅为现有 v2 Dialog 的底部抽屉、已有 i18n/控件样式，以及合约没有设备名时的
缩写设备地址；不应改变原型规定的流程或文案含义。
