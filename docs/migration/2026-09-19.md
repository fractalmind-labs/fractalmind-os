# Migration snapshot — 2026-09-19

This monorepo was assembled from the non-empty public repositories in
`fractalmind-ai`.

## Git migration

- 37 non-empty public repositories were imported.
- `feishu-onboarding-worker` was empty and is recorded in `repository-map.yaml`.
- Each source history was rewritten into its destination subtree with
  `git-filter-repo --to-subdirectory-filter`.
- Source commit counts were checked before and after rewriting; each imported
  repository retained the same number of commits.
- The source default branch was merged into `main`.
- Other source branches were published under `import/<repository>/<branch>`.
- Tags were published under `import/<repository>/<tag>`.

The path rewrite changes commit IDs because the tree root changes. Authors,
timestamps, messages, parent relationships, and file history remain present.

## Private repositories

GitHub's native repository-transfer endpoint was unavailable for this account.
The following same-name private repositories were created in `fractalmind-labs`
and populated with complete Git mirrors instead:

- `agent-console`
- `fractalmind-gateway` (archived)
- `fractalmind-memory`

Issues, pull requests, stars, watchers, and other GitHub metadata require a
separate migration because mirror pushes only transfer Git data.

## Historical skill catalog

`skills/registry/skills` retains the original catalog repository, including its
submodule metadata, for provenance. Canonical skill source histories are also
imported under `skills/coordination`, `skills/interfaces`,
`skills/development`, and `skills/validation`.
