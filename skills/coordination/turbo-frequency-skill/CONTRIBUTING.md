# Contributing to Turbo Frequency

Thanks for your interest in contributing!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-improvement`)
3. Make your changes
4. Test with your agent workspace
5. Submit a Pull Request

## What to Contribute

- **New signal sources** — More ways to detect busyness
- **Tier presets** — Alternative tier configurations for different use cases
- **Documentation** — Examples, translations, tutorials
- **Bug fixes** — If you find scoring edge cases

## Guidelines

- Keep SKILL.md as the single source of truth for agent instructions
- Signal scoring changes should be backward-compatible
- Include examples for new features
- Write clear commit messages

## Questions?

Open an issue or start a discussion.
