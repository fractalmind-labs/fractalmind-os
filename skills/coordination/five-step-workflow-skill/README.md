# five-step-workflow-skill

Skill instructions for combining first-principles thinking with Musk-style five-step workflow optimization.

## Compatibility

| Component | Requirement |
|---|---|
| Host OS | Linux/macOS/Windows (WSL supported) |
| Skill File | `SKILL.md` at repo root |
| UI Metadata | `agents/openai.yaml` |

## What it does

This skill helps an AI agent:
1. rethink the problem from first principles
2. redesign execution with the five-step method

Use it for products, processes, team rituals, operating procedures, and workflow redesign.

## Example prompts

- Use five-step-workflow to redesign our hiring process.
- Use five-step-workflow to optimize a product launch workflow.
- Use five-step-workflow to rethink and simplify a research pipeline.

## Included files

- `SKILL.md` — skill instructions
- `agents/openai.yaml` — UI-facing metadata
